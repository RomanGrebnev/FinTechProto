# Wealthpilot

AI-powered investment insights for French retail investors. **Phase 1: read and advise only, with no trade execution.**

Users fill in a risk profile, enter their holdings by hand, and get a dashboard showing their portfolio value, a measured risk score, market context and personalised recommendations generated by Mistral.

## Quick start

Requires Docker.

```bash
cp .env.example .env        # add your MISTRAL_API_KEY (optional, see below)
docker-compose up --build
```

- App: http://localhost:3000
- API docs (Swagger): http://localhost:8000/docs

Log in with the demo user: **demo@wealthpilot.fr / demo1234**. The demo user has a filled-in risk profile and 5 holdings (LVMH, Airbus, TotalEnergies, Amundi MSCI World, Apple).

### Environment variables

| Variable | Purpose |
|---|---|
| `MISTRAL_API_KEY` | Mistral API key. **If left empty, the app runs in demo mode** and returns rule-based recommendations, clearly labelled as such, so you can try everything without a key. |
| `DATABASE_URL` | SQLAlchemy URL. Docker Compose points it at the bundled Postgres. |
| `JWT_SECRET` | Secret used to sign auth tokens. Change it outside local dev. |

## Screens

1. **Sign up / log in**: email and password, JWT auth.
2. **Onboarding**: 6-step risk questionnaire, one question per screen: age, income, savings goal, monthly amount, risk tolerance (1–5), horizon.
3. **Portfolio**: add, edit or remove holdings (ticker, quantity, average buy price). The ticker is checked against Yahoo Finance when entered, and live values are converted to EUR.
4. **Dashboard**: portfolio value and P&L, a risk gauge (measured risk against the user's stated tolerance), allocation, the latest AI recommendations, and market context (CAC 40, Euro Stoxx 50, S&P 500, EUR/USD).
5. **Recommendations**: the full analysis: summary, 3 recommendations with rationale, a risk flag, and a rebalancing suggestion with a target allocation. The regulatory disclaimer appears on every screen that shows recommendations.

## How it works

```
frontend (React + Tailwind, nginx :3000) ──/api──▶ backend (FastAPI :8000) ──▶ Postgres
                                                        │
                                                        ├──▶ Yahoo Finance (yfinance): prices, FX, 1y history
                                                        └──▶ Mistral API (mistral-large-latest)
```

- **Prices** (`backend/app/prices.py`): one yfinance call per ticker returns the price, currency, instrument type and 1 year of daily closes. Results are cached in memory for 5 minutes. Non-EUR holdings are converted using the `XXXEUR=X` rate. If no price is found, the holding is valued at its buy price and marked "NO PRICE".
- **Risk score** (`backend/app/portfolio.py`): the portfolio's annualised volatility is computed from the covariance of aligned daily returns, then mapped to a 1–5 scale using bands loosely based on the EU PRIIPs SRI (3 / 7 / 12 / 20 / 30 %). A single stock above 40 % of the portfolio adds 0.5.
- **AI analysis** (`backend/app/advisor.py`): the server sends the risk profile, holdings and current prices to Mistral in JSON mode. The system prompt sets French context (PEA, assurance-vie, compte-titres, UCITS ETFs) and the exact output schema: 3 recommendations, 1 rebalancing suggestion with target allocation, and 1 risk flag. The response is validated with Pydantic and stored, so the dashboard shows the latest analysis without calling Mistral again. Each analysis is generated on demand with the **Analyse / Refresh** button.

## API

| Method | Path | |
|---|---|---|
| POST | `/api/auth/signup`, `/api/auth/login` | Returns `{access_token}` |
| GET | `/api/auth/me` | Current user and risk profile |
| PUT | `/api/profile` | Create or update the risk profile |
| GET | `/api/portfolio` | Holdings with live values, totals, risk score |
| GET | `/api/portfolio/lookup/{ticker}` | Validate a ticker and get its name and price |
| POST/PUT/DELETE | `/api/portfolio/holdings[/{id}]` | Manage holdings |
| POST | `/api/recommendations` | Generate a new analysis |
| GET | `/api/recommendations/latest` | Latest stored analysis |
| GET | `/api/market` | Index snapshot |

## Local development without Docker

```bash
# backend: uses SQLite if DATABASE_URL is unset
cd backend
python3.12 -m venv .venv && .venv/bin/pip install -r requirements.txt
.venv/bin/python seed.py
.venv/bin/uvicorn app.main:app --reload --port 8000

# frontend: Vite proxies /api to :8000
cd frontend
npm install && npm run dev   # http://localhost:5173
```

## Seed data

`backend/seed.py` is idempotent. It runs automatically each time the backend container starts and creates the demo user only if it doesn't already exist. To reset the database, run `docker-compose down -v`.

## Known limitations (Phase 1)

- Tables are created with `create_all` and there are no migrations yet. Add Alembic before the schema changes.
- yfinance is unofficial and can be rate-limited. Replace it with a licensed market-data feed before launch.
- Buy prices are entered in each instrument's own trading currency, and P&L is converted at today's FX rate, not the historical rate.
- Nothing has been reviewed by a regulator. Before offering personalised recommendations to the public in France, check whether the service requires CIF status with the AMF.
